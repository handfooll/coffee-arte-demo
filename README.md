# coffee-arte-demo

Concept site for Coffee Arte Gallery, a coffee shop and art gallery in Bishkek: menu, exhibitions, the ceramics workshop, and a background video from the studio.

Live: https://handfooll.github.io/coffee-arte-demo/

One page, plain HTML/CSS/JS. The video is a compressed WebM with a poster image, so the page renders right away even on slow connections. Content is in Russian.

Concept design, not commissioned by the cafe.
